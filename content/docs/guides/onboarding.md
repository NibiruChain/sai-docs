Welcome to Sai! This guide will walk you through the essential steps to start trading.

## Prerequisites

Before you begin, make sure you have:

* A supported wallet (see [Wallet Setup](/docs/guides/wallet-setup/))
* Collateral tokens (see [Acquiring Collateral](/docs/guides/acquiring-collateral/))

## Quick Start

1. **Connect Your Wallet** → [Wallet Setup](/docs/guides/wallet-setup/)
   * Set up your EVM or WasmVM compatible wallet
   * Configure your network for Nibiru
2. **Get Collateral** → [Acquiring Collateral](/docs/guides/acquiring-collateral/)
   * Learn how to bridge or purchase collateral tokens
   * Understand valid collateral types
3. **Choose a Market** → [Choosing a Market](/docs/guides/choosing-market/)
   * Explore available trading pairs
   * Understand oracle pricing
4. **Understand Leverage** → [Leverage & Risk Management](/docs/learn/trading/leverage-and-liquidations/)
   * Learn how collateral and leverage work
   * Understand liquidation mechanics

## Need Help?

* Having wallet issues? See [Wallet Setup](/docs/guides/wallet-setup/)
* Can't bridge assets? Check [Acquiring Collateral](/docs/guides/acquiring-collateral/)
* Questions about trading? Visit [FAQ](/docs/learn/trading/faq/)
