# Sai docs

This repository is the public Markdown mirror for Sai documentation. It gives
people a place to read the source and open GitHub issues about unclear,
outdated, or incorrect content.

The canonical source lives in the Sai Web repository:

`sai-web/docs-app/src/content/`

The current public snapshot is under [`content/`](content/):

- [`content/docs/`](content/docs/) contains product and developer documentation.
- [`content/blog/`](content/blog/) contains published blog posts.

These files are copied from Sai Web. Edit the canonical source there rather
than changing files in this mirror. Use [GitHub issues](https://github.com/NibiruChain/sai-docs/issues)
for questions, corrections, and suggestions.

The older documentation tree at the repository root is retained while this
public mirror is being reviewed. It is not the canonical source for the
current docs.
